# 프리코스 1주차 - 문자열 덧셈 계산기 

## 목적
입력된 양수를 구분자로 구분하여 덧셈하여 반환하기

## 요구사항
1. 쉼표, 콜론을 구분자로 하여 문자열을 구분한다
2. //구분자\n 와 같은 형태로 커스텀 구분자를 추가할 수 있다.
3. 잘못된 값이 들어오면 IllegalArgumentException 를 발생시킨다.
4. 문자열은 구분자, 양수로만 이뤄져있다.

## 주의사항
1. 빈값이 들어올 수 있다 - 0으로 반환.
2. 숫자는 양수만 들어온다.
3. 구분자는 여러개가 혼용되어 사용될 수 있다.

## 구현 기능 목록
#### 입력
- 문자열 입력 받기

#### 처리
- 커스텀 구분자 존재 여부 판단하기
- 커스텀 구분자 추출하기
- 커스텀 구분자 유효성 검사하기 - 검사 실패시 IllegalArgumentException 발생
- 숫자 추출하기
- 숫자 유효성 검사하기. - 검사 실패시 IllegalArgumentException 발생
- 숫자 모두 더하기
- 
#### 출력
- 덧셈 결과 리턴
